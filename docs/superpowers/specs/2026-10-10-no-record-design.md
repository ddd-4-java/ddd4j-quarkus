# 跨分支普通类类型统一

- 日期：2026-10-10
- 事实源：本仓库 Superpowers 规格。
- 授权：用户要求全分支写入禁用 record 规范并清理现有类型。

## 目标与兼容性

所有本地及远端版本、维护、历史备份分支的 Java 源码、测试、示例不再声明 record。使用普通不可变类保留构造参数、构造校验、组件访问方法、equals/hashCode/toString、接口、泛型与 Jackson JSON 字段契约。Java 类不再继承 java.lang.Record；这一类型变化由用户明确授权。嵌套类型显式 static，已有自定义成员保留。

## 验收

1. 每个分支扫描所有受 Git 管理的 Java 文件，无 record 声明。
2. 迁移类型编译，值语义和构造校验与原声明一致；HTTP DTO 的 JSON 序列化/反序列化保留字段名。
3. 仅转换目标类型与必要规范，不修改 Maven 版本、父 POM 或发布 shell。
4. 每个分支记录验证结果，提交后以远端 SHA 确认推送；环境阻塞不得表述为完整构建通过。
