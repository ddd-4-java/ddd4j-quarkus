# P0 — 基线基础设施实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 ddd4j-quarkus 基线基础设施（Cache BuildStep + Web Filter/Health/Exception + MQ Listener Registrar + parent 链重构），为 P1-P3 阶段提供统一基线
**Architecture:** Quarkus 原生扩展范式（@BuildStep + @Recorder + @ConfigMapping + CDI Producer），parent 链重构为 bom/dependencies/parent 三级 + 按域 profiles（ddd4j-web/data/schedule/excel/full）
**Tech Stack:** Quarkus 3.37.0 + ddd4j 2.0.x.20260630-SNAPSHOT + JDK 17/21 + Maven 3.9+
**Related Design Doc:** [../specs/2026-08-05-p0-baseline-infrastructure-design.md](../specs/2026-08-05-p0-baseline-infrastructure-design.md)
